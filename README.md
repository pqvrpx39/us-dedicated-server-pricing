## 先分清楚：你要的美国独立服务器是哪一种

美国独立服务器按用途分，大致是四类需求，对应的机器完全不同。

给大陆用户访问的网站和应用，核心在回程线路。市面上常被归为“高速直连”的线路有：电信 CN2 GIA（AS4809）、联通 CUII（AS9929）、移动 CMIN2（AS58807）、三网 AS4837，以及各类直连 BGP。线路决定晚高峰的延迟和丢包，也直接决定价格档位。

多 IP 业务（站群、多站点运营）看的是 C 段数量和 IP 资源，线路反而不是第一优先级。

大流量分发和持续传输——备份节点、下载站、流媒体中转——看的是端口规格和流量政策，1Gbps 起步、10Gbps 往上才谈得上大带宽。

容易被攻击的业务，要认准明确标注防御值的高防机型，下文细说。
